# Python Search Command Line Tool

The purpose of this project is to hack through python data structures, such as, dictionaries and lists.
As of now, there is no functionality included that makes this tool actually useful beyond using linux 'find' and 'grep' directly.

Eventually, this tool will become python-native and not rely on any linux subprocesses.
